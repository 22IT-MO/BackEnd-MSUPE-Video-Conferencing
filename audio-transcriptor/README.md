## 🚀 О проекте

Локальный сервер распознавания речи для платформы видеоконференций.  
Работает в реальном времени без подключения к интернету.  
Сохраняет полный текст лекции в формате Markdown `.md`.

---

## 📈 Архитектура решения

```
🎤 Микрофон пользователя
   ↓
🌐 Браузер (захват аудио через WebRTC)
   ↓ Socket.IO
💻 Сервер Flask
   ↓
🧠 Модель Vosk / KaldiRecognizer
   ↓
📄 Текст лекции в браузере + сохранение в файл
```

---

## 📦 Установка и запуск

```bash
# Установить зависимости
pip install flask flask-socketio vosk scipy numpy

# Скачать модель Vosk (например vosk-model-small-ru-0.22)
# Поместить в папку ./model

# Запустить сервер
python server.py
```

Открыть браузер:

```
http://localhost:5000/
```

---

## 🌐 Использование

- Нажмите **Старт записи** → начнется захват микрофона.
- В реальном времени будет появляться текст речи.
- Нажмите **Стоп записи**, затем **Скачать транскрипт**.
- Получите файл `.md` с лекцией!

---

## 📚 Основные компоненты

| Компонент | Описание |
|:---|:---|
| `server.py` | Прием аудио, пересэмплирование, распознавание через Vosk, отправка текста клиенту. |
| `index.html` | Работа с микрофоном, передача аудио через Socket.IO, вывод текста на страницу. |

---

## 🧠 Описание технологий

- **Vosk API** — офлайн-распознавание речи, поддержка русского языка.
- **KaldiRecognizer** — высокоточное потоковое распознавание.
- **Flask** — легкий серверный фреймворк для Python.
- **Socket.IO** — двусторонняя передача аудиоданных в реальном времени.
