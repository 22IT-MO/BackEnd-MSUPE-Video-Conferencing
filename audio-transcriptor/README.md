# 🎙️ Audio Transcriptor with Whisper + GPT Integration

Этот проект представляет собой веб-приложение для **распознавания русской и английской речи** в реальном времени с последующей генерацией **структурированного конспекта** лекции.

---

## 🚀 Возможности

- 🔊 Захват речи из микрофона в браузере
- 🧠 Распознавание с помощью `faster-whisper`
- 💬 Автоматическая генерация конспекта через GPT-подобные модели (g4f)
- 🗂️ Сохранение результатов в `.md` файлы:
  - `transcripts/raw/` — сырая транскрипция
  - `transcripts/cleaned/` — отформатированный конспект
- 🌐 Web-интерфейс с кнопками записи и скачивания

---

## 🏗️ Стек технологий

| Компонент      | Описание                                              |
| -------------- | ----------------------------------------------------- |
| Flask          | Web-сервер (Python backend)                           |
| Flask-SocketIO | Передача аудио в реальном времени                     |
| faster-whisper | Распознавание речи (OpenAI Whisper, оптимизированный) |
| g4f            | Доступ к бесплатным GPT-подобным моделям              |
| HTML/JS        | Интерфейс в браузере                                  |

## 📦 Установка

1. Клонируй репозиторий:

   ```bash
   git clone https://github.com/your-user/audio-transcriptor.git
   cd audio-transcriptor
   ```

2. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Убедись, что установлен `ffmpeg` (нужен для Whisper).

---

## 🧠 Генерация конспекта

Происходит через библиотеку [`g4f`](https://github.com/xtekky/gpt4free), которая перебирает список бесплатных GPT-провайдеров.  
При первом найденном работающем провайдере происходит генерация структурированного конспекта лекции с сохранением в `transcripts/cleaned/`.

> ⚠️ Если все провайдеры недоступны, будет сохранён только исходный `.md` файл.

---

## 🔧 Запуск

```bash
python server.py
```

Перейди в браузере по адресу:

```
http://localhost:5000
```

## 📝 Пример использования

1. Нажми **"Старт записи"**
2. Говори (можно на русском и английском, с математическими терминами)
3. Нажми **"Стоп записи"**
4. Нажми **"Скачать транскрипт"** или **"Скачать конспект"**
